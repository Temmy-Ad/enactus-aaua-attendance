First Time Setup

Connect to
Google Sheets

This is a one-time setup. Once done, all data lives in your Google Sheet and works across every device.

Follow these steps

1

Open Google Sheets

Go to sheets.google.com and create a new blank spreadsheet. Name it "Enactus AAUA Attendance".

2

Open Apps Script

In the Sheet, click Extensions → Apps Script. Delete everything in the editor.

3

Paste the script

Copy the Apps Script code from the second file you downloaded and paste it into the editor. Click Save (Ctrl+S).

4

Deploy as Web App

Click Deploy → New Deployment → Web App. Set "Who has access" to Anyone. Click Deploy. Copy the Web App URL.

5

Paste URL below

Paste the copied URL into the box below and tap Connect.
